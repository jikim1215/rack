# 변경 이력 — 정보시스템 자산관리 (itam)

버전은 `package.json` 의 `version` 하나가 정본이다(SemVer `주.부.수`).

| 올리는 자리 | 언제 |
|---|---|
| 주(major) | 되돌리기가 DB 복원 없이는 안 되는 변경 — 구판 앱이 새 스키마를 못 읽거나 데이터 형식이 바뀜 |
| 부(minor) | 기능·화면 추가나 변경, 운영 절차(배포·점검 스크립트) 변경 |
| 수(patch) | 기능 변화 없는 결함 수정 |

**확인하는 곳** — 로그인 화면 맨 아래(버전), 로그인 후 사이드바 맨 아래(버전 · 커밋, 마우스를 올리면 빌드 시각), `/api/health` 의 `version`·`commit`·`builtAt`, 번들 최상위 `VERSION` 파일, 반입 안내 `배포방법.txt` 첫 줄, 업그레이드·롤백 출력(`현재 → 새`).
커밋 뒤에 `-dirty` 가 붙어 있으면 커밋되지 않은 변경이 섞인 빌드다 — 정식 반입본이 아니다.

**릴리스 절차** — `npm version <x.y.z> --no-git-tag-version` → 이 파일에 항목 추가 → 커밋 → `git tag -a v<x.y.z>` → push(태그 포함) → 깨끗한 트리에서 `build-release.sh`.

## v1.1.0 — 2026-10-02

버전 표기를 도입한 첫 판. 이전 판은 모두 `/api/health` 가 `1.0.0` 으로 보고했다 — 아래는 그 판들과 비교한 변경이다.

### 버전 관리
- 화면(로그인 · 사이드바), `/api/health`, 번들 `VERSION` 파일, 배포·업그레이드·롤백 출력에 버전·커밋·빌드 시각 표시

### 데이터 보호
- ★ 구판은 서버를 재시작할 때마다 자산의 소유 팀 · 랙 L/R · 현행 확인 도장 · 일괄등록 배치 값을 비웠다 — 더 이상 지우지 않고, 업그레이드가 감사로그에서 빈 값만 되살린다
- 엑셀 일괄등록 · 배치 되돌리기 500 오류 수정(구버전 DB 의 `import_batch_id` 누락 자동 보강)
- `db-seed.mjs` 가 사용자 있는 DB 를 거부(운영 DB 전체 삭제 사고 방지)

### 보안
- 팀 간 격리 우회 차단 — 다른 팀 전용 위치에 랙·IP 대역·배선반 만들기, 다른 팀 자산을 부속의 상위로 연결하기
- 감사로그 누락 보강(위치 · 계약 · 업체 · IP 대역 · 포트 연결 · 반출입 · 확장 필드 · 메일 설정 · 비밀번호 변경)
- 엑셀 업로드: 압축 폭탄(작은 파일이 수백 MB 로 풀리는 zip) · 위장 파일 차단, `.xlsx` 만 허용
- CSV 내보내기 수식 주입 방지(`=`·`+`·`-`·`@` 로 시작하는 셀)
- 클라이언트 IP 위조 차단(허용 IP · 로그인 잠금 · 접속기록)
- Next.js 15.5.27 · nodemailer 10 · postcss 8.5.28 — 알려진 취약점 0건(`npm audit`)

### 웹 접근성 (KWCAG 2.2)
- 모든 입력칸 레이블, 화면별 탭 제목, 키보드로 카드·칸 열기, 본문 바로가기
- 대화상자 초점 가두기 · Esc 닫기 · 닫은 뒤 원래 자리로 복귀
- 글자 명도 대비 4.5:1 이상(어두운 배경 위 안내 문구 포함)

### 대량 데이터 (자산 1만 건 기준)
