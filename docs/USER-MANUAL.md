# 사용자 매뉴얼 — 정보시스템 자산관리

> ⚠️ 이 문서는 **`docs/사용자매뉴얼.md`**(현재 운영환경 반영 정본)로 대체되었습니다. 최신 내용은 그쪽을 보세요.

> 대상: 일반 운영자(팀 계정) · 열람자(viewer). 관리자 기능은 `docs/OPERATIONS.md` 참조.
> 화면마다 우측 상단 **"사용법"** 토글에 같은 내용의 요약이 있습니다. 이 문서는 업무 절차 순서로 재구성한 통합본입니다.

## 1. 시작하기

### 1.1 로그인
- 브라우저에서 시스템 주소 접속 → 계정/비밀번호 입력.
- 5회 실패 시 15분 잠금됩니다(본인 계정 + 접속 IP 기준).
- 최초 로그인 후 설정 → 비밀번호 변경(8자 이상, 영문/숫자/특수문자 2종 이상).

### 1.2 권한 이해
| 역할 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 총괄(admin) | 전체 | 전체 + 사용자/권한/로그/정리큐 |
| 팀(team) | **자기 팀 자산만** | 자기 팀 자산 등록·수정, 반출입 신청 |
| 전체열람(viewer) | 전체 | 조회만 (수정 버튼 비노출) |

- 다른 팀 자산은 목록에 나오지 않습니다 — 누락이 아니라 권한 정책입니다.
- 계약 정보는 전사 공유지만, 계약에 연결된 자산은 권한 범위 내에서만 보입니다.

### 1.3 세션
- 세션 수명은 기본 24시간(기관 설정에 따라 다름). 만료 10분 전 상단에 경고 배너가 뜨며 **[세션 연장]**을 누르면 계속 작업할 수 있습니다.
- 자산 폼 작성 중 내용은 자동 임시저장됩니다 — 만료·이탈 후 재진입하면 "이어서 작성" 배너로 복구하세요.

## 2. 일상 업무 절차

### 2.1 장비 반입 → 운영 (생명주기)
```
반입 신청(반입/반출) → 승인 → 완료 → 랙 실장(랙 실장도) → IP 부여(자산관리/IP관리) → 운용중
```
1. **반입/반출 메뉴**에서 신청 — 대장에 없는 장비는 '직접 입력'으로 기재하면 반입 완료 시 자산으로 자동 등록됩니다.
2. 완료 처리 후 토스트 안내에 따라 **랙 실장도**에서 미배치 패널의 장비를 랙 슬롯으로 드래그해 배치합니다.
3. **자산관리**에서 해당 자산에 대표 IP를 입력합니다 (공인 IP는 중복 시 저장 차단, 사설 IP는 허용).
4. 대시보드 "생명주기 흐름" 패널이 각 단계의 미완료 건수를 보여주며, 클릭하면 해당 작업 화면으로 이동합니다.

### 2.2 자산 등록/수정 (자산관리)
- 개별 등록: [자산 등록] 버튼. 직전 등록의 유형/망구분/랙 등 공통값이 자동 프리필됩니다.
- 대량 등록: [일괄등록] → 양식 다운로드 → 엑셀 작성 → 업로드.
  - 업로드하면 **먼저 검증 결과(반영 전)** 가 나옵니다: 생성 예정 건수, 기존 대장과 중복 의심 목록.
  - [가져오기 실행]을 눌러야 실제 반영됩니다. 결과 화면에서 생성 목록 CSV를 내려받아 보관하세요.
- 행 클릭 → 상세/수정 폼 + 변경이력(더 보기로 과거 전체 추적).
- 시리얼/자산번호가 "미입력"으로 표시되면 아직 채워지지 않은 값입니다.

### 2.3 랙 실장도
- 하단 1U → 상단 42U 표준 배치. 좌측 위치 필터로 사옥별 조회.
- **드래그**: 배치/이동 · **우클릭**: 실장 해제, 선번장 열기 · 실수 시 토스트의 **[실행 취소]**.
- 반폭 장비(L/R)는 같은 U에 두 대가 나란히 표시됩니다.
- 충돌(빨간 줄무늬+⚠)은 두 장비가 같은 슬롯을 차지한다는 뜻 — 호버하면 충돌 상대와 구간이 보입니다.

### 2.4 IP관리 (IPAM)
- 서브넷 격자에서 초록 셀(사용중)을 클릭하면 그 자리에서 대표 IP 수정/해제가 됩니다 (Enter 저장, Esc 취소, 실행 취소 지원).
- 미사용 셀 클릭 시 안내가 뜹니다 — 신규 할당은 자산관리에서 합니다.
- G=게이트웨이, N=네트워크, B=브로드캐스트 셀은 수정 대상이 아닙니다.
- 서브넷은 조회용 대역 정의라서 삭제해도 자산 IP는 지워지지 않으며, 사용중 IP가 있는 대역은 삭제가 차단됩니다.

### 2.5 배선관리 (선번장)
- 프레임 선택 → 페어 테이블에서 용도/장비포트 기재, 대향 프레임과 양단 링크.
- 선번 추적: 케이블ID/장비명/IP 아무거나 검색하면 양단 경로가 한 줄로 나옵니다.
- 엑셀 왕복: 다운로드 → 수정 → 업로드(셀 단위 병합 — 빈 셀은 기존 값을 지우지 않음, 충돌은 이슈로 보고).

### 2.6 자산실사
- 회차 선택 → 대상 목록(장비+부속)에서 [확인]/[분실]/[이동] 판정. 즉시 저장됩니다.
- 확인 외 판정 시 비고 입력창이 자동 강조됩니다 — **근거를 반드시 기재**하세요(감사 대응).
- 상단 "시리얼 불일치 참조 목록"은 관리대장과 시스템이 다른 장비입니다. 실물 시리얼을 우선 확인하세요.
- 마감은 관리자가 하며, 마감 후에는 기록·삭제가 불가합니다(증적 고정).

### 2.7 부속자산
- 모니터/키보드 등 소모성 자산. 연결 장비 열에서 어느 장비에 딸린 것인지 확인합니다.
- 장비급(스위치 등)이 부속에 잘못 들어간 경우 관리자에게 승격을 요청하세요.

## 3. 자주 묻는 질문

| 질문 | 답 |
|---|---|
| 다른 팀 자산이 안 보여요 | 정상입니다 — 행수준 팀 스코프 정책. 전체 조회가 필요하면 viewer 권한을 요청하세요 |
| 대시보드 숫자가 안 바뀌어요 | 대시보드는 조회 시점 스냅샷입니다. 새로고침하세요(상단에 기준 시각 표시) |
| 잘못 수정했어요 | 저장 직후라면 토스트의 [실행 취소]. 지난 뒤라면 변경이력에서 이전 값을 확인해 복구하세요 |
| 엑셀 업로드를 잘못했어요 | 관리자에게 배치 되돌리기를 요청하세요(업로드 결과 화면의 배치 ID 전달) |
| 반출한 장비의 IP가 남아있어요 | 정책상 반출 완료는 랙만 자동 해제하고 IP·부속 연결은 유지합니다(재반입 대비) |
