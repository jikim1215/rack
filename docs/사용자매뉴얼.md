# 사용자 매뉴얼 — 정보시스템 자산관리 (itam)

| 항목 | 내용 |
|------|------|
| 대상 | 일반 운영자(팀 계정) · 열람자(viewer) |
| 접속 주소 | **https://itam.example.go.kr/** (기관 내부 DNS 등록 필요) |
| 최종 갱신 | 2026-07-16 — 현재 운영환경(폐쇄망·공존시스템 공존) 반영 |
| 정본 안내 | 이 문서가 사용자용 최신 정본입니다. 관리자·서버 운영은 `docs/관리자매뉴얼.md` 참조 |

> 각 화면 우측 상단 **"사용법"** 토글에 같은 요약이 있습니다. 이 문서는 업무 순서로 재구성한 통합본입니다.

---

## 1. 시작하기

### 1.1 접속 (중요 — 반드시 도메인으로)
- 브라우저 주소창에 **`https://itam.example.go.kr`** 를 입력합니다.
- 이 서버는 자료공유(공존시스템, `share.example.go.kr`)와 **한 서버에 함께** 올라가 있습니다.
  **IP로 직접 접속(`https://서버IP`)하면 자산관리가 아니라 자료공유 화면으로 갑니다.** 항상 `itam.example.go.kr` 도메인으로 접속하세요.
- 인증서 경고가 뜨면 관리자에게 알리세요(정상 운영 시 경고 없음).
- 접속이 안 되면: ① 도메인 오타 ② 사내망(폐쇄망) 안에서 접속 중인지 ③ 관리자에게 DNS 등록 여부 문의.

### 1.2 로그인
- 발급받은 **계정 / 비밀번호** 입력.
- **5회 실패 시 15분 잠금**됩니다(본인 계정 기준). 잠기면 15분 뒤 자동 해제되거나 관리자가 해제할 수 있습니다.
- **최초 로그인 후 즉시 비밀번호 변경**: 설정 → 비밀번호 변경.
  - 규칙: **8자 이상**, 영문·숫자·특수문자 중 **2종 이상** 조합(최대 256자).
- 계정에 **접속 허용 IP**가 지정돼 있으면 그 IP(대역)에서만 로그인됩니다. 다른 자리에서 막히면 관리자에게 문의.

### 1.3 권한 이해
| 역할 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 총괄(admin) | 전체 | 전체 + 사용자/권한/로그/정리큐/실사마감 |
| 팀(team) | **자기 팀 자산만** | 자기 팀 자산 등록·수정·삭제, 반출입 신청 |
| 전체열람(viewer) | 전체 | 조회·다운로드만 (수정/삭제 버튼 비노출) |

- 다른 팀 자산은 목록에 **나오지 않습니다** — 누락이 아니라 행수준 팀 스코프 정책입니다.
- 미배정(팀 없는) 자산은 총괄만 봅니다. 팀 계정에 안 보이면 관리자에게 팀 배정을 요청하세요.
- 계약 정보는 전사 공유지만, 계약에 연결된 자산은 본인 권한 범위 내에서만 보입니다.

### 1.4 세션
- 세션 수명 기본 **24시간**(기관 설정에 따라 다름). 만료 **10분 전** 상단에 경고 배너가 뜨며, **[세션 연장]**을 누르면 계속 작업할 수 있습니다.
- 아무 활동이 없으면 연장되지 않고 만료 → 재로그인 필요(사실상 유휴 타임아웃).
- 관리자가 계정을 비활성화/역할 변경하면 **다음 요청부터 즉시** 반영됩니다(진행 중 세션도 무효).
- 자산 폼 작성 중 내용은 **자동 임시저장**됩니다 — 만료·이탈 후 재진입하면 "이어서 작성" 배너로 복구하세요.

## 3. 일상 업무 절차

### 3.1 장비 반입 → 운영 (생명주기)
```
반입 신청(반입/반출) → 승인 → 완료 → 랙 실장(랙 실장도) → 대표 IP 부여(자산관리/IP관리) → 운용중
```
1. **반입/반출** 메뉴에서 신청 — 대장에 없는 장비는 '직접 입력'으로 기재하면 **반입 완료 시 자산으로 자동 등록**됩니다.
2. 완료 처리 후 안내에 따라 **랙 실장도**에서 미배치 패널의 장비를 랙 슬롯으로 드래그해 배치.
3. **자산관리**에서 해당 자산에 대표 IP 입력(공인 IP는 중복 시 저장 차단, 사설 IP는 허용).
4. **대시보드 "생명주기 흐름"** 패널이 각 단계 미완료 건수를 보여주며, 클릭하면 해당 작업 화면으로 이동합니다.

### 3.2 자산 등록/수정 (자산관리)
- 개별 등록: **[자산 등록]**. 직전 등록의 유형/망구분/랙 등 공통값이 자동 프리필됩니다.
- 대량 등록: **[일괄등록]** → 양식 다운로드 → 엑셀 작성 → 업로드.
  - 업로드하면 **먼저 검증 결과(반영 전)** 가 나옵니다: 생성 예정 건수, 기존 대장과 중복 의심 목록.
  - **[가져오기 실행]**을 눌러야 실제 반영됩니다. 결과 화면에서 생성 목록 CSV를 내려받아 보관하세요.
  - 잘못 올렸으면 결과 화면의 **배치 ID**를 관리자에게 전달해 되돌리기를 요청하세요.
- 행 클릭 → 상세/수정 폼 + 변경이력(더 보기로 과거 전체 추적).
- 시리얼/자산번호가 "미입력"이면 아직 채워지지 않은 값입니다.

### 3.3 랙 실장도
- 하단 1U → 상단 42U 표준 배치. 좌측 위치 필터로 사옥별 조회.
- **드래그**: 배치/이동 · **우클릭**: 실장 해제·선번장 열기 · 실수 시 토스트의 **[실행 취소]**.
- 반폭 장비(L/R)는 같은 U에 두 대가 나란히 표시됩니다.
- 충돌(빨간 줄무늬 + ⚠)은 두 장비가 같은 슬롯을 차지한다는 뜻 — 호버하면 충돌 상대와 구간이 보입니다.

### 3.4 IP관리 (IPAM)
- 서브넷 격자에서 **초록 셀(사용중)**을 클릭하면 그 자리에서 대표 IP 수정/해제(Enter 저장, Esc 취소, 실행 취소 지원).
- **미사용 셀**은 안내만 뜹니다 — 신규 할당은 **자산관리**에서 대표 IP를 입력해 처리합니다.
- **G**=게이트웨이, **N**=네트워크, **B**=브로드캐스트 셀은 수정 대상이 아닙니다.
- 서브넷은 조회용 대역 정의라 삭제해도 자산 IP는 지워지지 않으며, 사용중 IP가 있는 대역은 삭제가 차단됩니다.

### 3.5 배선관리 (선번장)
- 프레임 선택 → 페어 테이블에서 용도/장비포트 기재, 대향 프레임과 양단 링크.
- 선번 추적: **케이블ID/장비명/IP 아무거나** 검색하면 양단 경로가 한 줄로 나옵니다.
- 엑셀 왕복: 다운로드 → 수정 → 업로드(**셀 단위 병합** — 빈 셀은 기존 값을 지우지 않음, 충돌은 이슈로 보고).

### 3.6 반입/반출
- 신청 → (승인 권한자) 승인 → 완료.
- **반입 완료**: 대장에 없던 장비는 자산으로 자동 등록.
- **반출 완료**: 랙 실장은 자동 해제되지만 **IP·부속 연결은 유지**됩니다(재반입 대비 정책).

### 3.7 유지보수
- 유지관리 대상/금액 탭에서 대상·계약금액 관리(엑셀 임포트 지원).
- 유지보수 이력 기록.

### 3.8 자산실사
- 회차 선택 → 대상 목록(장비 + 부속)에서 **[확인]/[분실]/[이동]** 판정. 즉시 저장됩니다.
- 확인 외 판정 시 비고 입력창이 강조됩니다 — **근거를 반드시 기재**(감사 대응).
- 상단 "시리얼 불일치 참조 목록"은 관리대장과 시스템이 다른 장비입니다. 실물 시리얼을 우선 확인하세요.
- **마감은 관리자만** 하며, 마감 후에는 기록·삭제가 불가합니다(증적 고정).

### 3.9 부속자산
- 모니터/키보드 등 소모성 자산. 연결 장비 열에서 어느 장비에 딸린 것인지 확인.
- 장비급(스위치 등)이 부속에 잘못 들어간 경우 관리자에게 승격을 요청하세요.

### 3.10 계약관리 / 통계 리포트 / 위치관리
- **계약관리**: 계약·업체·만료 임박(D-day) 확인. 계약에 자산 연결.
- **통계 리포트**: 브라우저 인쇄(Ctrl+P)로 PDF 저장/제출.
- **위치관리**: 사옥/층/실 정의(랙·자산 위치의 기준값).

## 4. 엑셀 업로드 공통 규칙
- 항상 **양식 다운로드 → 작성 → 업로드** 순서. 임의 양식은 열 인식이 안 됩니다.
- 업로드는 **① 검증(반영 전 미리보기) → ② 실행** 2단계. 실행 전에는 대장이 바뀌지 않습니다.
- 실행 결과 화면의 **생성/변경 목록과 배치 ID를 보관**하세요(문제 시 되돌리기 근거).
- 대량(수천 행)은 나눠서 업로드하면 안전합니다.

## 5. 자주 묻는 질문

| 질문 | 답 |
|---|---|
| 자산관리인데 자료공유 화면이 떠요 | IP로 접속했기 때문입니다. **`https://itam.example.go.kr`** 도메인으로 접속하세요 |
| 다른 팀 자산이 안 보여요 | 정상입니다(행수준 팀 스코프). 전체 조회가 필요하면 viewer 권한을 요청하세요 |
| 로그인이 15분 막혔어요 | 5회 실패 잠금입니다. 15분 후 자동 해제, 급하면 관리자에게 해제 요청 |
| 특정 자리에서만 로그인 안 돼요 | 계정에 접속 허용 IP가 지정된 경우입니다. 관리자에게 IP 추가 요청 |
| 대시보드 숫자가 안 바뀌어요 | 조회 시점 스냅샷입니다. 새로고침하세요(상단에 기준 시각 표시) |
| 잘못 수정했어요 | 저장 직후면 토스트의 **[실행 취소]**. 지난 뒤면 변경이력에서 이전 값 확인 후 복구 |
| 엑셀 업로드를 잘못했어요 | 결과 화면의 **배치 ID**를 관리자에게 전달해 배치 되돌리기를 요청하세요 |
| 반출한 장비의 IP가 남아있어요 | 정책상 반출 완료는 랙만 자동 해제하고 IP·부속 연결은 유지합니다(재반입 대비) |
| 세션이 자꾸 끊겨요 | 만료 배너의 **[세션 연장]**을 누르세요. 장시간 자리 비우면 유휴 만료됩니다 |
